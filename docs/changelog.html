v1.2.0

First public release November 25, 2026

RepoLens answers questions about the GitHub page you're on, in a side panel, using your own Claude, ChatGPT, or Gemini key. There is no RepoLens server and no account.

Ask about any GitHub page

  • Works on repositories, folders, pull requests, files, and commits, with suggested questions for each.
  • Instant answers from the page, diff, and README, or Deep answers that also read changed files, review comments, linked issues, configs, and CODEOWNERS.
  • Open the panel from the on-page lens, the toolbar popup, or Ctrl/⌘+Shift+L.

Your AI, your key

  • Bring an API key for Anthropic Claude, OpenAI (ChatGPT models), or Google Gemini. A free Gemini key works.
  • Pick the AI and model for each question from the side panel.
  • Compare: with two or more keys, send one question to several AIs and switch between their answers in tabs. GitHub context is fetched once, whatever the number of AIs.
  • Optional GitHub token for private repositories and higher GitHub limits.

Conversations

  • One conversation per repository, shared across its home page, folders, files, and pull requests, and kept when you come back.
  • Prefer one history per page? Switch it in Settings.

Popup, lens, and settings

  • Toolbar popup with the current page, the active AI, and a button to open or close the panel.
  • Hide the on-page lens on one repository or everywhere.
  • Settings save automatically and show whether each key works.
  • Optional lock: require Touch ID or Windows Hello before keys can be shown or changed.

Updates and feedback

  • A welcome page walks you through setup.
  • After an update, a What's new page shows the release notes.
  • Send bugs and ideas from the feedback page. Every message is read.

Privacy

  • Keys stay in your browser and are never synced. Each key is sent only to the service that issued it.
  • Page content is read only when you ask a question. No analytics, no tracking. Read the privacy policy.
