Privacy Policy

Last updated: November 25, 2026

RepoLens is a Chrome extension that answers questions about the GitHub page you are viewing. In short: RepoLens has no servers of its own and does not collect, sell, or share your data. Everything runs in your browser and talks directly to GitHub and to the AI provider you choose (Anthropic, OpenAI, or Google) using credentials you provide.

Where data is stored

All data RepoLens stores is kept in chrome.storage.local on your device. It is not synced to your Google account and is never sent to the RepoLens developer.

Third parties

RepoLens sends data only to these services, and only to do what you asked:

  • Your selected AI provider receives your question plus the page and repository context needed to answer it, authenticated with your own API key. Only the provider you select in Preferences receives data, and its handling of that data is governed by its own terms:
    • Anthropic (api.anthropic.com): anthropic.com/legal/privacy
    • OpenAI (api.openai.com): openai.com/policies/privacy-policy
    • Google Gemini API (generativelanguage.googleapis.com): Gemini API terms and Google privacy policy. Google may use data sent with free-tier Gemini API keys to improve its products; see Google's terms.
  • GitHub (api.github.com): receives read-only API requests for the repository you are viewing, authenticated with your GitHub token if you provided one. See the GitHub privacy statement.

If you enable Pre-fetch page context and have set a GitHub token, RepoLens requests basic context for repository pages from the GitHub API in the background as you browse github.com. This data goes only to GitHub and is not sent to any AI provider until you ask a question.

RepoLens contains no analytics, advertising, or tracking, and loads no remote code.

Update check: about twice a day, RepoLens asks GitHub (api.github.com/repos/mathinraj/RepoLens/releases) for the latest RepoLens release so it can tell you when an update or new release notes are available. The request contains no personal data and never includes your GitHub token.

Feedback and uninstall survey

Feedback links (toolbar popup, Preferences, welcome and What's new pages) open the feedback form. When RepoLens is uninstalled, Chrome opens a short survey at repolensio.vercel.app/uninstall.html. Both links carry these diagnostics in the URL: RepoLens version and store build, browser and version, operating system, selected AI provider and model, whether an API key and a GitHub token are set (yes/no), number of answers received, and days since install. They never include API keys, tokens, repository names, questions, or answers.

The pages show you those diagnostics, and you can untick them before sending. Nothing is sent unless you press Send. When you do, your message, the diagnostics you chose to include, and your email address (only if you enter one) are delivered to the developer by email through EmailJS. The website is hosted on Vercel, which may keep standard request logs (including page URLs) as described in Vercel's privacy policy.

Your control

  • Clear a conversation: use the Clear button in the side panel.
  • Remove credentials: delete them on the RepoLens Settings page.
  • Key lock: optionally require Touch ID or Windows Hello before keys are shown or changed on the Preferences page. It protects the page, not the stored data: keys are not encrypted.
  • Delete everything: uninstall the extension; Chrome deletes all of its stored data.
  • Revoke access: revoke your AI key with its provider (Anthropic, OpenAI, Google AI Studio) or the GitHub token at github.com/settings/tokens.

Data use commitments

RepoLens does not sell user data, does not use or transfer it for purposes unrelated to answering your questions, and does not use it to determine creditworthiness or for lending.
