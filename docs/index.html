Private by design

There is no RepoLens server. The extension talks straight to GitHub and the AI provider you choose.

  • Your keys stay in your browser. Stored locally, never synced, and each key is sent only to the service that issued it.
  • Page content is read only when you ask. Nothing is sent to an AI provider until you ask a question.
  • No analytics, no ads, no tracking. No account to create.
  • Open source. Read every line on GitHub.
