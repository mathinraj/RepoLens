How to create a token
  1. Open GitHub's new fine-grained token page.
  2. Under Repository access, choose the repositories RepoLens may read.
  3. Under Repository permissions, set Contents, Pull requests and Issues to Read-only. Metadata is read-only automatically.
  4. Generate the token and paste it above. RepoLens never writes to GitHub.
