Pin RepoLens to your toolbar One click to open the panel, see your setup, or change settings.
  1. Click the Extensions button (🧩) in the Firefox toolbar
  2. Click the gear (⚙) next to RepoLens
  3. Choose Pin to Toolbar
✓ RepoLens is pinned to your toolbar

Welcome to RepoLens

Ask AI about any GitHub repo, pull request, file, or commit, right beside the code.

Get set up

  1. 1

    Choose an AI provider and add your key

    Use Claude, ChatGPT (OpenAI), or Gemini. A free Gemini key works too.

  2. 2

    Add a GitHub token optional

    Needed for private repos and higher GitHub limits. Public repos work without one.

  3. 3

    Try it on a pull request

    Open a sample PR, click the blue lens, and pick "Summarize this PR".
